# IoT-system-to-collect-vital-signs-via-sensors
The objective of this project is to build a smart IoT system capable of continously collecting vital signs through sensors, enabling timely health assessment and abnormal condition alerts based on ESP32 and MAX30102
# Environment & Installation
Python Version: Python 3.9+ (Python 3.11 – 3.14 recommended)
Dependencies: numpy, scipy, matplotlib
